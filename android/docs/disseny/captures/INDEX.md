# Captures

Cada pantalla en clar (`-clar`) i fosc (`-fosc`). Mida lògica 390 × 920 dp, exportades a 2x.
Tipografia i icones substitutes (Inter i icones Material aproximades); colors, mides, espais i jerarquia són els definitius.

| Fitxer | Què mostra |
|---|---|
| `01-escalfant-auto` | Encès, escalfant, mode Automàtic: programa d'avui amb el tram actiu editable |
| `02-menu-estat` | Menú del xip d'estat obert: Activa · Pausa · Apaga |
| `03-repos-manual` | En repòs (ja a la consigna), mode Manual: consigna −/+ i temperatures ràpides |
| `04-temporal` | Automàtic amb canvi temporal: bàner «Temporal fins a les 14:00» |
| `05-pausa` | En pausa: paleta lila, consigna a recuperar atenuada i amb vora discontínua |
| `06-apagat` | Apagat: sense lectura de temperatura («—»), controls desactivats |
| `07-refrescant` | Pull‑to‑refresh en curs |
| `08-carrega` | Càrrega inicial (skeleton) |
| `09-error-api` | Error de l'API de Tuya amb acció a iot.tuya.com |
| `10-sense-connexio` | Sense connexió a internet |
| `11-falta-config` | Estat buit: falta la configuració |
| `12-configuracio` | Pantalla de configuració |
| `13-config-prova-ok` | Provar connexió: correcta |
| `14-config-prova-error` | Provar connexió: error |
| `15-widgets-i-rajola` | Widgets 2×1 i 4×2 i rajola de configuració ràpida, en clar i fosc |
| `16-wear-os` | Wear OS: app (escalfant, en pausa, llista), tile, complicacions i estat sense configurar |
| `17-android-auto` | Android Auto: GridTemplate en actiu i en pausa |
| `18-icona` | Icona adaptativa, màscares del llançador, icona temàtica i Wear |
| `19-programa-edit` | Programa setmanal: selector de dia, barra de 24 h i 6 trams |
| `19-programa-copy` | Full inferior «Copia el dilluns a» amb dies i dreceres |
| `19-programa-time` | Selector d'hora d'inici d'un tram |
| `19-programa-copied` | Després de copiar: dies marcats com a modificats i Snackbar |
